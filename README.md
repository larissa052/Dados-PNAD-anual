# 📊 Análise de Dados PNAD Anual

Este repositório contém scripts em **R** para análise dos dados da **Pesquisa Nacional por Amostra de Domicílios (PNAD)**.

## 📌 Recursos
- 📊 Processamento de dados da PNAD
- 📈 Visualização estatística em R
- 📑 Relatórios automatizados

## 🔧 Como usar
1. Clone este repositório:
   ```sh
   git clone https://github.com/larissa052/Dados-PNAD-anual.git
   ```
2. Execute os scripts `.R` no RStudio.
